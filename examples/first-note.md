# Alpha Project Facts

This is a sample source for the agent2kb first-run tutorial (docs/first-run.md). The project
described here is fictional; every fact below is fixed so that the compiled page and the answer
to a query can be checked by eye.

- The alpha project has the codename **Lantern**.
- It was started on 15 January 2026 by a team of four people.
- It publishes a new release every six weeks.
- Its documentation is written in Markdown and stored in a bucket named `alpha-notes`.
- The team meets every Tuesday to review open questions.

## Why the codename

The team chose Lantern because the project's first goal was to make existing notes easier to
find, in the way a lantern makes a dark room easier to search.
